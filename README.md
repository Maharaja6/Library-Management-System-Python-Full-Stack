# Library Management System

A web-based Library Management System developed using Python and Flask that allows users to display, borrow, and return books.

## Features
- Display available books
- Borrow books
- Return books
- User-friendly interface

## Tech Stack
- Python
- Flask
- HTML
- CSS
- Jinja2

## Project Structure

Library Management System
│
├── app.py
├── templates/
│   └── index.html
├── static/
│   └── style.css

## Installation & Run

pip install flask

python app.py

Open in browser:

http://127.0.0.1:5000
